# Pandas in Python 

A structured, hands-on learning repository documenting my journey with **Pandas**, a powerful Python library for data manipulation and analysis.

This repository contains practical Python programs, code examples, and exercises covering fundamental Pandas concepts, with an emphasis on understanding how to work with structured datasets.

## 🎯 Learning Objectives

- Understand Pandas Series and DataFrames.
- Perform data selection, indexing, and slicing.
- Manipulate and filter structured datasets.
- Handle missing values and clean datasets.
- Explore data aggregation, grouping, and sorting.
- Import and export datasets using CSV and Excel files.
- Build practical data analysis projects.

## 🛠️ Technologies Used

- **Language:** Python 3.11
- **Library:** Pandas
- **Supporting Library:** NumPy
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub
